自然数减法的结果不一定还是自然数。这说明自然数对减法**不封闭**。

数学不允许这种“有时行，有时不行”的局面。

怎么解决？

直接**让“差”成为新的对象**，将自然数扩展成整数。

定义：一个**整数**就是一对自然数 $(a, b)$，它代表 $a - b$。

等等，集合没有顺序，怎么区分 $a - b$ 和 $b - a$ ？

需要先解决[有序组合](./有序组合.md)的定义。

有序组合解决了，但同一个整数有多种表示法：

- $(2, 0)$ 代表 $2 - 0 = 2$
- $(3, 1)$ 代表 $3 - 1 = 2$
- $(4, 2)$ 也代表 $4 - 2 = 2$

所以需要把这些“表示同一个整数”的自然数数对归为一类。

这就引出了**等价类**的概念。

### 等价关系

在正式构造整数之前，需要先定义一个工具：等价关系。

**关系** $R$ 是集合 $A \times A$ 的一个子集。如果 $(a, b) \in R$，我们记作 $a \sim b$。

一个关系 $\sim$ 被称为**等价关系**，如果它满足三条性质：

1. **自反性**：$\forall a, \; a \sim a$
2. **对称性**：$\forall a, b, \; a \sim b \Rightarrow b \sim a$
3. **传递性**：$\forall a, b, c, \; (a \sim b \land b \sim c) \Rightarrow a \sim c$

等价关系把所有对象划分成若干个**等价类**：每个类里的对象都互相等价，不同类的对象不等价。

### 整数的构造

在自然数对 $\omega \times \omega$ 上定义关系：

$$
(a, b) \sim (c, d) \quad :\Longleftrightarrow \quad a + d = b + c
$$

$(a, b)$ 代表 $a - b$，$(c, d)$ 代表 $c - d$，它们相等当且仅当 $a - b = c - d$，由减法定义和等式性质得 $a + d = b + c$。

**验证这是等价关系**：

1. **自反性**：$(a, b) \sim (a, b)$ 因为 $a + b = b + a$。

2. **对称性**：如果 $(a, b) \sim (c, d)$，则 $a + d = b + c$，所以 $c + b = d + a$，即 $(c, d) \sim (a, b)$。

3. **传递性**：如果 $(a, b) \sim (c, d)$ 且 $(c, d) \sim (e, f)$，则 $a + d = b + c$ 且 $c + f = d + e$。两式相加得 $a + d + c + f = b + c + d + e$，消去 $c + d$ 得 $a + f = b + e$，即 $(a, b) \sim (e, f)$。

所以 $\sim$ 是等价关系。

**整数集** 定义为：

$$
\mathbb{Z} := (\omega \times \omega) / \sim
$$

即所有等价类的集合。

每个整数是一个等价类 $[(a, b)]$，代表 $a - b$。

例如：

- $0 := [(0, 0)] = [(1, 1)] = [(2, 2)] = \cdots$
- $1 := [(1, 0)] = [(2, 1)] = [(3, 2)] = \cdots$
- $-1 := [(0, 1)] = [(1, 2)] = [(2, 3)] = \cdots$

### 整数的加法

在整数上定义加法：

$$
[(a, b)] + [(c, d)] := [(a + c, b + d)]
$$

**但这里有个问题**：等价类 $[(a, b)]$ 有无数个代表元。比如 $2$ 既可以写成 $[(2, 0)]$，也可以写成 $[(3, 1)]$、$[(5, 3)]$……

那么用不同的代表元算，结果会不会不一样？

$$
[(2, 0)] + [(1, 0)] = [(3, 0)] \quad (\text{代表 } 3)
$$

$$
[(3, 1)] + [(1, 0)] = [(4, 1)] \quad (\text{代表 } 3)
$$

结果都是 $3$。但这只是试了一个例子，必须证明它对**所有**代表元都成立。

#### 良定义性

要证明加法是**良定义的**，即：如果

$$
(a, b) \sim (a', b') \quad \text{且} \quad (c, d) \sim (c', d')
$$

那么

$$
(a + c, b + d) \sim (a' + c', b' + d')
$$

**证明**：

由假设，$a + b' = b + a'$，且 $c + d' = d + c'$。

两式相加：

$$
a + b' + c + d' = b + a' + d + c'
$$

整理得：

$$
(a + c) + (b' + d') = (b + d) + (a' + c')
$$

按 $\sim$ 的定义，这正是：

$$
(a + c, b + d) \sim (a' + c', b' + d')
$$

所以加法与代表元的选取无关，是良定义的。

#### 性质

之前只在自然数里证明了加法的性质，现在换成了整数，需要重新证明。

*下列字母均表示自然数*

**交换律**：

$$
\begin{align}
[(a, b)] + [(c, d)] &= [(a + c, b + d)] \\
&= [(c + a, d + b)] \\
&= [(c, d)] + [(a, b)]
\end{align}
$$

**结合律**：

$$
\begin{align}
([(a, b)] + [(c, d)]) + [(e, f)] &= [(a + c, b + d)] + [(e, f)] \\
&= [((a + c) + e, (b + d) + f)] \\
&= [(a + (c + e), b + (d + f))] \\
&= [(a, b)] + [(c + e, d + f)] \\
&= [(a, b)] + ([(c, d)] + [(e, f)])
\end{align}
$$
