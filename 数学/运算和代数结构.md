# 运算
数是造出来了，但光有数没有用。数字存在的意义是运算。

## 加法
加法怎么定义？  

直觉上，加法就是“往后数”：`a + b` 就是从 `a` 开始，往后数 `b` 次。  

所以可以这样定义：

$$
\begin{align}
&a + 0 = a\\
&a + S(b) = S(a + b)
\end{align}
$$

试试 2 + 3：

$$
2 + 3 = S(2 + 2) = S(S(2 + 1)) = S(S(S(2 + 0))) = S(S(S(2))) = S(S(3)) = S(4) = 5
$$

好的，看上去没什么问题。

那么，加法有什么性质？

注意到：

$$
\begin{align}
1 + 2 &= 3\\
2 + 1 &= 3\\
(1 + 2) + 3 &= 3 + 3 = 6\\
1 + (2 + 3) &= 1 + 5 = 6\\
\end{align}
$$

好像交换运算顺序不好影响结果。

但这只是“好像”。我们需要证明它。

尝试证明?

首先，我们需要[∈-归纳法](./∈-归纳法.md)：

$$
\forall x,  [\forall y \in x,  P(y) \Rightarrow P(x)] \Rightarrow \forall x,  P(x)
$$

### 加法的性质

有了 ∈-归纳法，我们可以严格证明加法的两个性质：**结合律** 和 **交换律**。
#### 结合律

$$
\forall a, b, c,  [(a + b) + c = a + (b + c)]
$$

固定 $a$ 和 $b$，对 $c$ 做 ∈-归纳：  
$\forall a, b,$  
$c = 0$ 时，由加法定义得：

$$
(a + b) + 0 = a + b = a + (b + 0)
$$

$c = 0$ 时结合律成立。  

假设 $(a + b) + c = a + (b + c)$ ，则：

$$
\begin{align}
(a + b) + S(c) &= S((a + b) + c) \\
&= S(a + (b + c)) \\
&= a + S(b + c) \\
&= a + (b + S(c))
\end{align}
$$

结合律得证。
#### 交换律

$$
\forall a, b,  [a + b = b + a]
$$
固定 $a$ ，对 $b$ 做 ∈-归纳：  
$\forall a,$  
$b = 0$ 时，由加法定义得：

$$
a + 0 = a
$$

但是 $0 + a$ 等于什么？加法定义里没有说。  
先证明： $\forall n \in \omega,  [0 + n = n]$ ：  
对 $n$ 做 ∈-归纳。
$n = 0$ 时，$0 + 0 = 0$，成立。  
假设 $0 + n = n$，由加法定义得 $0 + S(n) = S(0 + n) = S(n)$ 。

所以：

$$
\begin{align}
a + 0 = a \\
a + 0 = 0 + a
\end{align}
$$

$b = 0$ 时交换律成立。  
假设 $a + b = b + a$ ，接下来证明 $a + S(b) = S(b) + a$ :  

$$
\begin{align}
a + S(b) &= S(a + b) \\
&= S(b + a) \\
&= S(b) + a
\end{align}
$$

等等，为什么 $S(b + a) = S(b) + a$ ？  
这也需要证明。

$$
\forall a, b, \; S(b + a) = S(b) + a
$$

固定 $b$，对 $a$ 做 ∈-归纳。

$a = 0$ 时 $S(b + 0) = S(b) = S(b) + 0$ 成立。  
假设 $S(b + a) = S(b) + a$，证明 $S(b + S(a)) = S(b) + S(a)$：

$$
\begin{align}
S(b + S(a)) &= S(S(b + a)) \\
&= S(S(b) + a) \\
&= S(b) + S(a)
\end{align}
$$

这下逻辑没问题了，交换律得证。
