# 真理
## 这个仓库怎么来的
当我进入高中，原本以为终于能学习世界的**真理**了，结果……  
仔细思考了一下，甚至有些知识都**不逻辑自洽**  
然后就有了这个仓库  
在这里，只有严谨的证明，没有需要背诵的八股文  

还有一份高中遇到的所有逆天事件记录（*注：为防止被学校发现，这个记录将在高考结束后再公开*）。  

## 如何贡献

如果你也是一名受够了高中理科的学牲，觉得自己快被逼疯了，别随波逐流。
坚持逻辑，把你的思考和证明写在这里。**真理不需要被考试分数认可。**欢迎向这个仓库发起 PR (Pull Request)！
